## 本任务验收
1. 用户详情首屏完整显示头像、昵称、用户名、UID、状态、基础/附加组、实际成长等级/EXP、积分、当前权益及勋章数量，未授权和未初始化明确区分。
2. 分类按概览、会员身份、有效权限（原能力门槛）、内容、账号安全、管理记录（原能力门槛）；举报迁入内容内，保留搜索/分页/错误恢复。键盘切换与焦点不回退。
3. 聚合读取绑定当前 UID；过期请求或能力变化不能展示旧档案；失败可只重试档案，不打断账号资料。
4. 会员身份集中显示组来源/原因/期限、成长进度/服务端下一等级、积分、勋章及权益完整记录。复用固定 UID 的组/积分独立写入；成功刷新首屏、档案与列表。积分保留原回执及未知结果同键确认。组加入/移出未知结果保留参数和键、阻断离开；409 明确刷新版本并保留原因。
5. 本任务不增加接口或 Schema；不提供未实现的 EXP/续期/勋章按钮。M04 仍 NOT DONE，T02 后端流水/EXP、T03 权益续期、T04 勋章写回执后再完整验收。
6. 1440/1024/768/390/320，浅/深主题，无整页横向溢出，保存真实 API 浏览器截图。
