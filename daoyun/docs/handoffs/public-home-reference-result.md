# 前台首页参考图完成记录

日期：2026-10-11

## 实现结果
- 公共首页调整为宽屏三栏布局，保留顶部搜索、主题切换、账户菜单和移动端底部导航。
- 快捷发布栏展示当前用户头像，文字、图片、链接和发布按钮接入现有发布窗口。
- 统一无图、单图、双图、三图卡片的作者、等级、正文、标签和操作结构；双图与三图等宽并排，单图按实际宽高比选择缩略或宽图。
- 授权图片预览、服务端剩余图片数量、点赞、收藏、主题跳转继续复用原功能。
- 右侧账户卡显示本人 EXP 与下一等级进度、真实积分、公开勋章数、本人主题总数；失败值为未知并支持重试，账号变化首帧隐藏旧数据。
- 社区热议按已加载公开主题显示，可换一批；近期作者来自相同公开内容，明确展示范围。加入入口和发现更多社区有实际导航或登录行为。
- 修正侧栏热帖链接的修饰键点击，保留浏览器新标签页操作。移除卡片和搜索框不成对的颜色过渡，避免深色切换瞬间白底白字。

## 独立核验收敛
- 已修复侧栏链接无条件拦截 Ctrl/Cmd 等点击的问题，并先用失败测试确认。
- 板块网格疑点核实不成立：最终样式由 styles.boards.css 的 marker/title/cover/actions 区域规则控制，原四区域规则已被覆盖；板块 DOM 结构保持，五宽度公共回归通过。
- 公开摘要 hook 使用既有按用户名共享的请求和 60 秒缓存，避免多作者身份重复请求；新私有数据读取单独取消与隔离。公开组以服务端 public_groups 契约为准，不增加不存在的公开标记字段。

- 未新增依赖、后端接口、数据库数据或迁移，未提交或推送，保留原有后台与成长奖励插件改动。
