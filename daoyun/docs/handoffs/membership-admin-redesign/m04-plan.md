状态：DONE，当前 PAUSED，未进入 M05。2026-10-06，用户继续授权此阶段。以最新阶段划分为准，不导入旧未接入草稿。

## 目标与边界

用户在一个 UID 的详情上下文中查看账号、全部可读会员领域与已有操作。复用 GET /api/v1/admin/users/{id}/membership-summary；账号 GET 独立保留，聚合失败可单独重试。无权、未初始化、空记录与加载失败分别展示；当前等级、下一等级和权益历史来自服务端，不以积分推算 EXP，不由界面重算权限。

六标签按概览、会员身份、有效权限、内容、账号安全、管理记录排列；权限检查和审计保留既有能力门槛。内容包含原内容及举报搜索/分页；状态和治理角色移至账号安全。所有 tab 控制目标稳定存在，惰性业务面板访问后保留，切换时保留操作草稿与回执。顶部头像/昵称/用户名/UID/状态及基础附加组、Lv/EXP/进度、积分、有效权益、勋章数量。

仅前端与相关行为测试/CSS/文档。不新增依赖、API、Schema、迁移或自动提交。管理员 EXP 调整与 EXP/积分分页流水归 M05，原子权益续期归 M06，勋章独立操作回执缺口归 M05；不制造这些按钮/流水。已有组、积分、勋章、权益、角色命令保持独立 capability、CSRF、原因、revision/幂等语义。未知结果禁止盲目重发，已有幂等命令保留原输入和 key；无独立回执的勋章只允许读取核实。
