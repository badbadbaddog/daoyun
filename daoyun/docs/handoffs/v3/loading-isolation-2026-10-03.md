# DYR-006 页面数据与错误隔离

状态：DONE。DYR-003–006 的 G1 已接受，整体继续执行，未提交、未部署。

## 最终行为

- 会员按账号与页签加载：成长只请求 experience/catalog；积分读取余额与流水；权益、勋章独立。概览只组合成长、余额与用户组，详细列表由对应入口加载。概览单项失败保留其余摘要，不把未知余额显示为 0。
- 页签/账号/认证状态变化取消旧请求。渲染数据必须匹配 userId:tab；旧请求即使完成也不得覆盖当前页面。会话探测失败显示可重试错误，不永久停留在加载中。
- 后台初始化仅确认权限与作用版块；品牌、邮件、版块配置由对应区域加载，各自独立 loading/error/retry。SMTP 500 不阻断举报，版块摘要失败不冒充零，也不隐藏账号任务。各管理业务面板使用 React lazy/Suspense。
- 显式声明全局 feed 的使用范围；直接版块详情只请求本版块主题。搜索结果不再作为侧栏“今日热帖”；用户搜索和主题搜索分别错误/取消。分页请求同样支持 AbortController，来源切换或卸载会取消。
- 工作台滚动恢复等待所用摘要，包括版块摘要，完成或失败后再执行。
