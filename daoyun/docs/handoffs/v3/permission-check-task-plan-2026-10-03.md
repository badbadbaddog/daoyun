# DYR-013 权限检查执行方案

## 已批准边界

承接用户批准的 V3 三十卡计划，前置 DYR-002、011、012 已完成。A12 独立只读检查页放在管理团队导航；具体用户、版块、五种社区动作及必要资源条件。只检查服务端当前时刻，返回带时区的服务端快照时间，界面按本机时区显示，不模拟历史或未来权限。

复用现有权限矩阵的用户来源快照、真实权限 union、额度 MAX、账号及局部限制判定；在同一 REPEATABLE READ / READ ONLY 事务内补齐主题状态、锁定、上传归属、文件大小、原文件下载额度与内容策略。不得写入额度、积分流水、附件、治理或审计记录。来源最多 128，单语句超时两秒；不返回正文、存储路径或管理角色内部权限。

接口 GET /api/v1/admin/permission-check，严格参数枚举与 UUID、上下文匹配、正文件大小及 50 MiB 服务上限；授权检查先于主体／资源查询，要求与矩阵指定用户检查一致的七个读取能力。响应和错误均关联 request_id；Cache-Control: no-store；公开 DTO 及生成的 TypeScript 契约。结果仅供检查，真实请求重新鉴权、验证文件并原子消费。
