# UI V2 第九增量：发布器会话失效恢复

开始日期：2026-10-01；收尾日期：2026-10-02。对应 DYV2-010 / P-10。P-10 本轮接受；P-01/P-02/P-04/P-07/P-08/P-09 真实回归通过。DYV2-010 和整体方案仍 IN_PROGRESS，G0–G5 全部 NOT_ACCEPTED。冻结九文件未修改；FastSpider_FS 未调用。

## 实现与契约

- 只把 401 auth.unauthenticated 识别为会话失效；403 auth.csrf_failed 仍显示普通操作错误。沿用现有端点、DTO、错误信封及 x-request-id，无后端、数据库迁移或依赖变更。
- 发布、上传、草稿和版块能力请求报告失效时，立即以当前编辑值保存原账号本地草稿，保留标题、富文本、图片顺序、版块和投票；停止上传与云草稿队列，清除当前页面认证状态。失效稿不写入 guest 键。用户仍可编辑、移除及排序已有内容，上传和发布需要重新登录。
- 登录窗口显示期间暂停发布器弹窗及焦点约束，组件状态保留。失效时及取消登录后将焦点移到重新登录按钮；在身份弹窗关闭的微任务之后恢复，避免桌面焦点回到首页。失效稿不启用编辑器自动聚焦，提示不会被编辑器滚动遮住。
- 原账号以新会话登录后恢复原内容、版块及云草稿元信息，重新查询版块能力与投票策略，权限未确认前禁止写入。新的只读限制和真实配额 429 均重新生效；重新登录不自动提交，用户明确发布后才产生主题。
- 切换至另一个已验证账号先切换草稿作用域再显示编辑器，不暴露旧标题、正文、图片或云草稿；返回原账号可恢复原稿。晚到的旧 CSRF 草稿 401 通过请求的 AbortSignal 排除，不能撤销新登录。
