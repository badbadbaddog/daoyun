# UI V2 第三增量：授权图片聚合与完整查看器

日期：2026-09-30。源码提交：2e6bc3031231df680413c1b0789c7609ca2df4b0。原执行方案未修改，本地工具继续执行的授权保持有效。整体方案和 G0–G5 仍未完成。

## 已实现

- TopicSummary 新增必填 visible_image_count；TopicDetail 新增必填 media_urls。列表只返回前三张；详情查看器按正文顺序查看全部授权图片。见独立 media-contract-change-2026-09-30.md。
- 候选收集不提前截断。附件需 ready、clean、未删除、绑定当前主题，并同时通过主题和附件权限。作者、已回复用户和全局超级管理员可以纳入已解锁门控图片；未解锁用户看不到 URL、alt 和数量。批量查询复用现有授权边界。
- Feed 第三张显示真实剩余数，版块缩略图也显示可见剩余数。详情正文保留原渲染结构，移除不可用图片；统一查看器不会在正文末尾重复插图。
- 查看器支持加载、失败重试、关闭取消、键盘切换、缩放和回焦。重试成功会把焦点移回弹窗内，弹窗标题栏不再产生重复 banner。
- 查看器直接使用授权缩略图 URL。原图端点保留现有登录、下载权限和配额检查，不根据缩略图地址推导下载地址。
