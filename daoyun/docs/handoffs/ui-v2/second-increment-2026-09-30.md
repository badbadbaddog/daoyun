## 已实现行为

- 目录沿用 GET /api/v1/boards 的分页可见数据及真实 parent_id，父项可进入详情或独立折叠。搜索同名节点时显示完整可见路径；搜索和展开状态写入 #boards?q=...&expanded=...，刷新和返回保留状态。
- 详情按面包屑、轻量头部、子版块导航、置顶、搜索及排序、紧凑帖子行、加载更多的顺序呈现。子版块在小屏换行，不依赖右栏。
- 列表和搜索始终传当前 board slug；界面明确“仅显示本版帖子”。latest/active/hot/featured 保留 URL，分别沿用 latest/active/popular 与 featured=true 查询，不改变排序权重。
- 发布入口遵守服务端 viewer.canCreateTopic，并把当前 board.id 传给既有发布器。只读版块显示能力说明。
- 版块帖子行的点赞、回复、收藏使用独立控件，移除列表及版块侧栏缺乏计量证据的浏览数。无标题图片帖保留可键盘打开的“查看图片帖”链接，不制造持久化标题。
- 目录/详情请求在账号 ID 改变时清除缓存并重新加载，退出后不会保留旧私有版块名称、帖子和发布能力。
- 加载更多使用独立 AbortController。版块、搜索、排序或详情状态变化时中止请求，迟到的旧分页结果不能拼到新列表。
- 清理旧版块详情专属 CSS，统一 320/390/768/1024/1440 布局。小屏主要控件至少 44px；图片行使用 56×56 缩略图；搜索框常驻显示；保留时间信息。
