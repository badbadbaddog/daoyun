# 授权图片聚合契约变更

范围：UI V2 第三增量，API v1 的增量字段；原执行方案保持冻结。

- TopicSummary 新增必填 visible_image_count，等于当前用户可访问的正文图片去重总数；image_urls 仍只返回前三张缩略图，image_url 等于首张。
- TopicDetail 新增必填 media_urls，按正文顺序返回完整授权图片缩略图 URL；正文保留原富文本结构，排除不可用图片节点。查看器直接使用服务端提供的授权图片 URL，原图下载保留既有权限和配额，不在正文末尾重复插入图片。
- 回复门控图片只有作者、已发布且未删除回复的用户、全局超级管理员可见。匿名和未解锁会员不能得到它们的 URL、alt 或数量。
- 图片须同时通过主题与附件内容权限，且 ready、clean、未删除、绑定当前主题、MIME 为 image。候选收集先于授权，预览截取晚于授权。列表聚合批量查询，不逐主题查询。
- 不增加端点或数据库迁移；继续保持业务响应 envelope 与 x-request-id 相同。生成 OpenAPI 后用现有 generate-api-client 脚本更新 TypeScript 类型，客户端严格验证计数和列表一致性。
- 验收：九图顺序、前三张列表、第三张剩余数、完整九图查看器；私有/扫描/删除/回复门控过滤；错误重试、关闭/卸载取消、键盘切换及回焦。发布端九图上限和排序持久化属于后续发布增量，本次不宣称已验收。
