# 公共前台双栏列表复刻

## 目标与验收
按用户 2026-10-11 最新参考图复刻：公共顶部导航（首页、社区、交易、中介、发现、活动、更多）、搜索、发布、通知和账户；前台共用同一导航组件。首页左侧紧凑主题列表、右侧欢迎与注册登录、快捷入口、热门板块、交易市场、近期作者，不添加列表上方山景横幅或快捷发布大卡片。主题显示头像、标题、置顶、标签、作者、时间、板块、回复和浏览；点赞收藏继续可用。

桌面公共内容、导航和页脚最大宽度为 1200px，居中显示；小于该宽度时按现有响应式规则适配。大屏不继续拉伸；验证 1279/1280px 断点及 1920/2560px 宽屏。

## 数据边界
复用现有 React/TypeScript、Lucide、API 数据与路由。交易、中介、活动使用对应社区检索入口；市场展示交易板块已加载公开主题，无内容显示空态，不伪造商品、价格或全站统计。用户数和在线人数接口尚未支持，显示未知；主题统计注明来自公开板块。保留真实个人账户与成长数据。

## 实现顺序
1. 先增加失败行为测试。
2. 修改 SiteHeader 公共导航，TopicFeed 使用 TopicRow 紧凑列表展示，恢复五个分类。
3. 修改首页右栏与样式；公共页面双栏布局，手机保留公共导航入口与底部导航。
4. 运行测试、类型检查、构建和实际浏览器验证。

## 代码及验证
组件位于 src/components，公共装配位于 src/app/CommunityApp.tsx；样式在 src/styles.home.css，颜色使用 src/styles.css/共享语义 token。组件命名导出，文件 UTF-8，不新增依赖、后端接口或数据库变更。

命令：pnpm test；pnpm typecheck；pnpm build；pnpm test:e2e:typecheck；pnpm exec playwright test e2e/public-home-reference.spec.ts --project=chromium-desktop --workers=2。

浏览器验证 320/768/1024/1440px、深浅主题、注册登录、搜索、发布、公共导航跨页、列表主题与作者跳转、加载失败重试、空状态及 axe 无障碍。

## 继续打磨（2026-10-12）
保持 1200px 居中和无横幅布局。公共主导航在桌面与小屏弹窗使用相同选中态：首页各信息流归属首页，板块检索与主题详情归属社区，交易等具体入口单独选中。“更多”点击外部、焦点移出、Escape 和页面切换均收起，Escape 返回触发按钮。普通列表行收紧为约 64px；长标题截断后可悬停查看完整文本，多标签自动换行且不能挤没标题；窄侧栏五个近期作者完整展示。增加上述行为与 320/768/1024/1280/1440px 长内容回归。
