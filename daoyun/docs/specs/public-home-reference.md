# 前台首页参考图实现

## 目标
按 2026-10-11 用户参考图调整公共首页：宽屏三栏、顶部搜索和账户、快捷发布、作者在上方的内容卡片、多图横排、单图自适应、个人成长与统计、社区热议、近期作者、加入社区入口。

## 范围和边界
- 复用现有主题、板块、会员、头像、图片预览和发布流程，无新增依赖或接口。
- 首页统计取本人积分账户和个人资料；勋章取公开摘要，未知值显示占位，可重试；切换账号立即清除旧账户数据。
- 仅展示明确公开的身份；不将私人组、权益或其他人的积分带到内容卡片。
- 热议来自当前已加载公开主题，保留主列表服务端排序；无今日热度或成员排行榜接口，因此标题用社区热议、近期作者，并标明数据范围。
- 常用社区沿用公开目录，保留全部入口；不增加无后端支持的编辑或收藏。
- 快捷栏使用现有文字、图片、链接入口，并增加发布按钮；参考图表情和 @ 不做空按钮。
- 纯文字不补封面；单图按照真实宽高比，宽图铺开，非宽图缩略显示；保留授权预览和剩余图片数量。
- 样式归属 styles.home.css，使用语义颜色 token，圆角不超过 8px；板块列表保持现有模式。

## 追加要求
用户明确要求统一单图、双图、三图、无图四种卡片状态，分别覆盖桌面与移动端，保持同一作者、标签和操作结构。

## 验收
- 1440/1536 宽屏三栏，320/390 手机单栏、768/1024 平板无横向溢出。
- 浅色/深色、访客/登录、空列表/加载/请求失败可用。
- 搜索、主题与作者跳转、主题预览、发布、主题标签筛选、个人菜单和主题点赞收藏保持可用。
- 本人统计显示真实总量，加载失败不伪装为 0，退出/换号不闪现旧数据。
- 新行为先补失败测试，再实现；运行 Vitest、应用与 E2E 类型检查、生产构建和浏览器验证。
