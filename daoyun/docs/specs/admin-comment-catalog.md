# 评论管理目录页

依据用户提供的评论管理截图，使用真实评论接口，沿用后台主题。

## 验收
- 四项已加载数据统计：评论数、公开、隐藏、涉及主题；不显示虚构的全站数量或待审状态。
- 按授权板块、公开/隐藏状态和正文/用户名搜索；最近 7/30 天仅过滤已加载结果，提供重置、20/50 条游标加载。
- 紧凑七列表格包含勾选、正文摘要、作者、原帖、时间、状态和详情入口；勾选可导出摘要 CSV，标明被截断的正文。
- 所有屏幕统一使用右侧覆盖式模态抽屉，打开时列表宽度与列布局保持不变；完整正文、用户、主题、ID、创建/更新时间、上/下一条、复制评论定位链接。
- 隐藏/恢复必须填写原因，保留 CSRF、updated_at 并发校验、重复提交保护和失败重试；操作中不能切换或关闭。
- 详情请求切换时取消旧请求；分页失败能重试，切换筛选不会混入旧响应。
- 在状态筛选中隐藏后再次恢复，评论按发布时间返回列表，统计同步且不会重复；时间比较按实际时间处理时区。
- 关闭详情后恢复到评论操作按钮；原行已移除时回到搜索框。
- 不新增接口未提供的 IP、客户端、历史记录、图片预览、删除或待审操作。
- 覆盖 320/768/1024/1440、浅深主题、键盘与无新增浏览器错误。
