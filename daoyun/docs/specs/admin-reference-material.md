# 后台素材视觉对齐

## 目标与范围
按用户提供的 DaoYun_DZ风格_后台界面_分离素材八张参考图，统一后台的蓝色横向分类导航、浅蓝上下文侧栏、面包屑、白色工作区、表格及编辑表单。保留已实现模块及权限、数据、路由、错误处理；不添加素材中的未实现业务或虚构数据。

## 验收与顺序
1. 顶部分类只显示有授权模块的分类，点击进入已有模块；当前分类和面包屑同步。先写失败行为测试，再实现导航。
2. 侧栏在工作台展示全部授权入口，进入业务页展示当前分类；移动模块选择器保留全部授权入口。
3. 样式使用 packages/design-tokens/tokens.css 的后台语义令牌，复用现有 Lucide 图标；圆角不超过 8px。
4. 表格表头、分区标题、选中标签、表单及弹窗采用参考图的紧凑蓝白视觉。
5. 320/768/1024/1440px、浅深主题无页面横向溢出；搜索、分类跳转、折叠和主题切换可用，无无障碍违规。

## 技术与目录
React 19、TypeScript、Vite。外壳 src/components/AdminView.tsx，令牌 packages/design-tokens/tokens.css，样式 src/styles.admin.css，行为测试 src/components/AdminView.test.tsx。沿用命名导出和既有状态，例如 `<button type="button" onClick={() => onNavigate?.(module.tab)}>{module.label}</button>`。不新增依赖或 API。

## 验证
`pnpm test`、`pnpm typecheck`、`pnpm build`；浏览器验证真实本地后台与 axe，并保存预览截图。

## 边界
始终保留现有权限和 CSRF；不修改后端、数据库与公开社区布局，不提交生成产物或秘密。用户已授权按素材修改后台，本规格将该指令落实为可验证的视觉及导航要求。
