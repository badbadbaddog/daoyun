# 后台功能补齐

## 授权与目标
用户已确认补齐参考菜单缺失的真实功能，优先评论管理与内容审核。保留既有未提交修改与既有域模型，不添加演示数据或空菜单。

## 范围与默认决策
1. 评论管理：复用 posts 的 reply 记录；按授权版块查询、搜索、状态筛选、游标分页、查看完整正文、隐藏/恢复。变更需处理说明与 updated_at 并发令牌，事务更新回复统计和审计；不硬删除。
2. 内容审核：首先提供独立编辑审核工作台，覆盖主题与回复待审版本；版块范围 moderation.topic 即可处理，无需全站配置权限。策略配置仍留在插件设置。新内容发布前审核独立列为后续切片，不把编辑审核伪装为发布审核。
3. 标签管理：真实标签目录、使用数量、创建/改名/合并；引用更新须原子完成，保留标签搜索语义。
4. 活动管理：遵循 ADR-008 官方插件边界，首版为免费活动发布、起止时间、报名名额、报名/取消和名单；不引入支付。
5. 内容分析、用户分析、运营报表：复用已采集的聚合数据；明确 UTC、采集缺口、样本和窗口，支持 7/30/90 天与 CSV 导出，不泄露用户明细。
6. 任务队列：真实 Outbox/插件任务状态、分页、失败详情与受控重试；不允许重放已成功任务或修改载荷。
7. 日志审计：复用 audit.read 查询，按操作/资源/人员筛选与分页，只读，不提供清理历史入口。
