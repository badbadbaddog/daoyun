# 后台主题与工作台改版

## 目标与授权
用户提供后台参考图，并在讨论布局调整后明确要求开始实施。采用分组侧栏、紧凑顶栏、摘要卡、趋势与快捷入口双栏；待办优先，保留现有业务流程。

## 范围与验收
- 顶栏支持检索并跳转已授权模块；桌面侧栏可折叠，窄屏保留模块选择器。
- 摘要使用真实举报、限制账号与隐藏版块数据；分页数量标记 +，加载和失败不显示为零。
- 有运营权限时显示最近七日趋势，可切换主题、回复和新增用户；缺失采集不连线、不伪装为零。
- 快捷入口来自既有可见模块，保持权限裁剪；举报详情跳转保留过滤参数。
- 使用现有语义色、Lucide、8px 以内圆角；浅深主题及 320/768/1024/1440px 无横向溢出。

## 实现顺序
1. 先补摘要跳转、模块搜索/折叠与趋势切换的失败测试。
2. 调整 AdminView 外壳、AdminDashboard 布局及独立趋势组件。
3. 在 styles.admin.css 调整局部样式；运行组件测试、类型检查和构建。
4. 浏览器核对布局、权限与交互；审查改动。

## 技术与目录
React 19、TypeScript、已有 Vitest/Testing Library/Playwright；无需新增依赖。组件和测试位于 src/components，样式位于 src/styles.admin.css，规格位于 docs/specs。
使用命名导出和现有 API，例如：
```tsx
export function AdminDashboard() { /* 工作台呈现 */ }
```

## 验证命令
- pnpm test
- pnpm typecheck
- pnpm build
- pnpm test:e2e

## 边界
始终保留现有未提交业务改动、权限与错误处理。新增依赖或后端契约变更需另行确认。不新增虚构统计、不改数据库、不提交构建产物或秘密。

- 全量 Vitest：97 个文件、732 项通过；最终相关组件与样式复测 58 项通过。
- TypeScript 项目检查、Vite 生产构建通过。
- 本地真实 API 后台：320/768/1024/1440px 浅深主题均无页面横向溢出，模块搜索、菜单折叠、摘要筛选跳转、移动模块选择及趋势切换通过。
- axe：桌面/手机的浅色与深色均无违规；修复自定义品牌色继承导致的深色强调文字对比度不足。
- 独立审查两条线索已复核：基础样式已定义网格；新增用户直接来自 users 注册记录，采集缺口标记只约束活动/内容事件。

## 按管理任务组织导航
工作台单独置顶；内容管理包含主题、举报与风控；社区运营包含版块、用户、会员经济与角色权限；数据分析包含数据总览；系统设置包含品牌、插件、邮件与运维。桌面、手机共用权限裁剪后的分组，空组不显示；原路由保持不变。主题管理明确对应已有主题治理页面。本轮不增加未实现模块的空入口。

导航验证：AdminView 与 App 共 110 项测试通过，类型检查与构建通过；真实页面验证主题管理与数据总览跳转，四种屏宽浅深主题无横向溢出，桌面/手机 axe 无违规。
