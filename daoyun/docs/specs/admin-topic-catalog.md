# 主题管理目录页

依据用户提供的主题管理截图，沿用现有管理外壳，调整为操作栏、四项统计、搜索筛选、紧凑主题表格和游标加载。

## 验收
- 统计显示当前板块已加载主题、已公开、已置顶、已精选，不伪造全站总数。
- 搜索继续通过服务器检索；治理状态和最近 7 / 30 天筛选作用于已加载结果，重置恢复默认。
- 表格独立显示主题、作者、板块、互动、状态和发布时间；勾选仅用于导出当前筛选中的选中行。
- CSV 包含 UTF-8 BOM，正确转义逗号、换行、引号并阻止公式执行；按钮明确导出范围。
- 发布入口复用现有编辑器；成功后刷新主题列表，失败保留编辑内容。
- 隐藏、驳回、置顶、精选、锁定、移动、历史和并发修订校验保持原行为。
- 不伪造封面、标签、待审核/删除数量、内容类型或页码；接口未提供这些数据。
- 320 / 768 / 1024 / 1440 宽度和深色主题可用；菜单键盘操作、焦点和可访问标签保留。

## 验证记录（2026-09-22）
- 前端完整回归缓存覆盖全部 102 个测试文件，无失败；最终定向回归 30 个用例通过。
- TypeScript 类型检查、Vite 生产构建通过。
- 本地真实 API：搜索空结果、重置、每次 20 / 50 条、游标追加（20 → 28）、勾选单条 CSV 下载通过。
- 发布复用现有编辑器，打开/关闭与焦点恢复通过；此轮未向数据库新增测试主题。
- 1440 / 1024 / 768 / 320 宽度无页面横向溢出，1024 表格无内部列溢出。
- 浅色和深色页面的 axe WCAG 2 A / AA、WCAG 2.1 AA 检查均无违规；浏览器无 pageerror。
- 预览截图：artifacts/admin-topic-catalog/desktop.png、mobile.png。
