# 后台交互改版

用户于 2026-09-05 批准可点击设计预览并授权实施。

## 目标与范围

- 保留统一后台入口，按日常管理、社区运营、站点设置组织导航。
- 用户列表不常驻详情：点击用户打开速览抽屉；状态与角色操作使用弹窗。
- 举报队列与核查详情分开展示；处置表单按需打开弹窗，保留组合影响确认。
- 角色目录、人员授权、长权限编辑分开展示；分配角色使用弹窗。
- 插件安装保留现有四步向导，放入弹窗；调用工具按需打开。
- 运维概览、告警、规则使用独立视图，单条规则按需编辑。
- 品牌配置按设置类别分开；风控告警列表与策略编辑分开。
- 版块和会员工作区已有的编辑弹窗与抽屉继续使用，统一后台外观。

## 实施约束

使用 React、TypeScript、既有 ModalDialog/Drawer 和语义颜色令牌，不增加依赖。
保留现有 API、capability、CSRF、revision 冲突处理和完整业务字段。
所有修改使用 UTF-8。现有公共社区及后端未提交改动不属于本次改版范围。

## 顺序与验收

1. 用户抽屉及操作弹窗：列表筛选保留，关闭恢复焦点，提交错误保留草稿。
2. 举报详情与处置：返回队列保留列表，处置保留事务式请求和影响确认。
3. 权限、插件、运维和配置：进入编辑后不同时展示无关列表/表单。
4. 全局布局：紧凑侧栏与列表，移动端模块选择，320/768/1024/1440px 无页面横向溢出。
5. 测试、类型检查、构建、浏览器关键流程及代码审查。

组件测试在 src/components/*.test.tsx；浏览器测试在 e2e/。
命令：`pnpm test`、`pnpm typecheck`、`pnpm build`、`pnpm test:e2e`。
先添加关键交互的失败测试，再实施相应变更。
