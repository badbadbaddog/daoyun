# 管理后台基础切片规格

## 目标

为 super_admin 提供站点品牌配置和社区板块配置的最小服务端闭环。公开客户端可以读取当前品牌配置；管理写入必须使用服务端会话、CSRF 和角色校验。

## 范围

- 单例站点品牌：站点名称、Logo/Favicon URL、主色、强调色、官方预设、列表密度和首页模式。
- 板块管理：读取活动板块、创建板块、更新板块和无主题板块软删除。
- 管理审计：每次品牌或板块写入记录操作者、资源、操作和结构化摘要。
- 暂不实现二进制 Logo 上传、管理后台 React 页面、举报与 RBAC 扩展角色。

## 验收标准

- 未认证用户可以读取公开品牌配置，但不能读取管理板块或写入接口。
- 只有拥有 super_admin 角色的有效会话可以读取管理板块和执行品牌/板块写入。
- 所有状态改变请求同时要求会话 Cookie、匹配的 CSRF Cookie 和 x-csrf-token。
- 品牌字段、板块 slug/名称/描述/图标/色调/排序/可见性在 API 边界和数据库约束双重校验。
- 删除板块只能软删除，且存在主题时拒绝删除；公开板块查询不会返回已删除或隐藏板块。
- 每次成功写入产生一条不可变的管理审计记录，错误响应不泄露 SQL 或凭据。
- OpenAPI、统一 envelope、运行时 DTO 和数据库正反迁移均有测试覆盖。

## 边界

- 始终：复用现有 Cookie 会话、CSRF、super_admin 查询和统一错误 envelope。
- 先不做：新增依赖、公开写接口、对象存储和运行时主题注入。
- 禁止：把密码、Cookie、CSRF 或数据库错误写入响应和审计摘要。
