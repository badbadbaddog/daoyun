# 后台用户组与附件额度配置

## 目标

在“会员经济”中增加“用户组”工作区，让有社区用户组管理权限的管理员查看用户组，并通过弹窗编辑附件上传限制；拥有 `super_admin` 角色的管理员不受社区附件业务额度限制。

## 验收标准

- 后台“会员经济”出现“用户组”工作区，以紧凑列表展示名称、标识、成员类型和附件额度。
- 点击“配置额度”打开弹窗，可编辑单文件大小、每日上传数量、总存储空间和每日下载流量。
- 表单使用易读单位，提交时转换为现有 API 所需的整数额度；保存成功后刷新列表并展示成功反馈。
- 只读权限可查看列表但不能修改；无用户组读取权限时不展示该工作区。
- `super_admin` 上传附件时绕过用户组的每日数量、单文件大小和总存储业务额度；普通用户仍按所属用户组执行额度。
- 不新增用户组 API 或数据库迁移，复用 `/api/v1/admin/community/groups` 及现有 `quotas` 契约。
- 支持 320、768、1024、1440 像素宽度，弹窗支持键盘关闭和焦点恢复。

## 实现边界

- 不在本次增加内容草稿功能。
- 不允许删除系统基础组，也不在本次实现成员批量调组。
- 管理员豁免仅针对附件业务额度，不绕过文件类型校验、请求解析、鉴权或系统安全限制。

## 验证

- 前端行为测试覆盖列表、只读状态、弹窗保存和单位换算。
- 后端测试覆盖管理员豁免与普通用户继续受限。
- 运行 `pnpm test`、`pnpm typecheck`、`pnpm build`、Rust 定向测试和格式检查。
- 在本地浏览器验证用户组列表、弹窗和移动端布局。
