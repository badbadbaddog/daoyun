## 本方案收敛的默认方向

首页单列、非瀑布；帖子图文与纯文字共享骨架；正文优先且标题可空；Feed最多展示当前用户可见的前3图，发布上限9图；版块保留父子结构，不是圈子；公开身份与私人会员数据分开；后台待办优先，重组六个一级分组，不删既有功能。

前面的生成图片仅是视觉探索稿。成员数、浏览量、访客、认证勾、封面编辑、活动、注册审核、插件更新提示等不能直接当已实现能力。字段来源和权限优先于“照图实现”。

沿用现有React/TypeScript/Vite与Rust/PostgreSQL/Wasmtime体系；不迁移Nuxt、不重写API、不新增支付/交易订单/主题市场。已存在的深色/紧凑/高对比能力保留兼容，浅色为主验收方向。
