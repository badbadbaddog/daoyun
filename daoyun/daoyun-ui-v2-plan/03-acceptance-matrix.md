## 1. 使用规则

用例结果填写 PASS / FAIL / BLOCKED / NOT_RUN / N/A。N/A 必须写明该能力经基线核对不属于现有范围；缺账号、设备、数据库或接口环境只能记 BLOCKED，不能当 N/A。

每条结果关联任务编号、角色、数据集、环境、源码标识、命令/步骤、证据路径与问题单。视觉截图只是其中一种证据，权限、事务和真实动作必须有 API/E2E 或数据库侧验证。

下文每条用例默认 NOT_RUN。任务文档中的区间引用指本文件对应编号，不代表一条测试代码必须一一对应一条产品验收；可以参数化，但报告必须保留场景覆盖。

Q-08 是线上观测记录项，不作为部署前代码候选的必需门禁。未采集真实样本时保持 NOT_RUN 并写明样本不足；不能标 PASS 或宣称真实性能达标。其余任务规定的必需检查依照门禁执行。

## 2. 环境与数据集

| 维度 | 必需覆盖 |
|---|---|
| 角色 | 未登录、普通会员、帖子作者、受限会员、限定版块版主、局部管理员、超级管理员 |
| 版块 | 无子版块、至少三级层级、同名子版块、只读、受限、隐藏、已合并；状态以当前契约为准 |
| 帖子 | 有/无标题、纯文字、1/2/3/9图、公开与受限图片混合、长文、代码/表格/引用、隐藏/删除、编辑待审 |
| 评论 | 0条、多页、深层回复、删除楼层、非首屏深链接、隐藏引用、作者编辑和无权操作 |
| 会员 | 动态/最高等级、积分0/非0/未知、公开和内部组、有效/将生效/到期/耗尽权益、兑换插件状态 |
| 插件 | 宿主关闭、未安装、停用、启用、无权限、执行错误、历史内容保留；六官方插件按受影响面覆盖 |
| 视口 | 320、390、768、1024、1440 CSS px；另做文本放大与320 CSS px重排 |
| 主题 | 默认浅色全覆盖；深色/紧凑/高对比覆盖壳、卡片、正文、弹层、表单、表格代表页 |
| 网络 | 成功、慢响应、断线、第二页失败、401、403、409、429、5xx、请求响应乱序 |
| 浏览器 | 当前项目支持范围内的 Chromium/Firefox/WebKit；版本现场记录；移动真机另列 |

不要机械穷举所有维度的笛卡尔积。每页五宽度布局、每个安全边界多角色、每个新组件代表主题和键盘路径为必需；再对高风险发布/治理/积分/插件做组合场景。

真机和浏览器引擎模拟分开记录；无法访问真实 IdP/硬件 Passkey 的完整流程如原本就是待扩展，记录继承限制及本轮触及范围。新 UI 修改导致无法验证的关键路径不能用旧限制掩盖。

## 3. 缺陷等级与放行

| 等级 | 示例 | 放行规则 |
|---|---|---|
| P0 阻断 | 越权/私密泄露、丢草稿/正文、重复扣积分、主要路径不可用 | 立即停止扩大改造/发布，修复或回退 |
| P1 重要 | 核心旧链接失效、关键移动动作不可达、待审展示错误、主要状态不准确 | 必须解决后放行受影响里程碑 |
| P2 一般 | 非关键对齐/间距/次级反馈瑕疵，无数据和权限影响 | 明确记录、范围和后续任务；不得称零问题 |

代码交付状态与生产上线状态分开。无线上样本不阻塞报告真实实验室结果，但不得写真实用户指标达标；关键真机/授权/数据一致性检查缺失则按对应门禁阻塞。

| X-04 | 插件失败 | 制造插件超时/错误/额度耗尽 | 宿主按既有策略限制；局部退化不阻断主页面 | 错误注入 |
| X-05 | 历史保留 | 投票/补充/审核等有历史内容后停用插件 | 遵守各自现有保留规则，不丢历史或绕过审核 | 真实集成 |

## 5. 量化验收目标与来源

本项目将主要移动操作命中区域设为至少44×44 CSS px。WCAG 2.2 AA 2.5.8 的24×24 CSS px最低要求及例外是另一个标准层级，不能混写。文字对比度、重排与模态焦点规则参考下列官方资料。

| 检查 | 验收目标 | 来源/性质 |
|---|---|---|
| 文本对比 | 普通文字≥4.5:1；大字≥3:1 | W3C SC1.4.3 |
| 重排 | 一般纵向内容在320 CSS px宽不丢信息/功能、不需整页二维滚动 | W3C SC1.4.10，必要二维内容有例外 |
| 点击区 | 移动主要操作项目目标44px；核对AA最低24px及间距等例外 | 项目目标 + W3C SC2.5.8 |
| 模态焦点 | 进入、限制、关闭后返回，背景不可操作 | W3C APG Dialog Modal |
| 真实体验性能 | 按设备分类的p75：LCP≤2.5s、INP≤200ms、CLS≤0.1 | web.dev Web Vitals；不是当前成绩 |
| 体积预算 | 同环境压缩脚本增长超过基线10%须评审 | 本项目预算，不是外部行业标准 |

实验室性能至少记录构建、数据集、浏览器、视口、CPU/网络配置与多次运行中位数；真实p75需真实用户样本。自动扫描通过不等于完成全部可访问性验收，人工键盘与主要读屏语义仍须检查。
