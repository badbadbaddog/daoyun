# 前后台界面规格与原型索引

本章是实现规格，不把38张设计页当作38个新增业务系统。可交互文件在`prototype/index.html`，截图在`designs/`。所有人物、额度和统计是演示数据。源码已具备的能力优先复用，设计未接线的操作不是已实现功能。

## 1. 视觉和交互基线

浅色主验收：品牌蓝#2563EB、主文字#18243B、弱背景#F5F7FB、白色内容区；采用现有设计令牌映射，不全仓替换CSS。桌面侧栏约222px，主内容留24–32px；8px间距节奏；常规正文14–16px，页标题24–28px。表格重信息密度，不用大卡片替代所有列表。错误用文字/图标说明，不仅依赖颜色。

桌面1440/1024，平板768，手机390与窄屏320分别验收。页面不能整体横向溢出；确需横向比较的表格仅在自身容器滚动，并提供手机单场景视图。实施目标为主要触控区域44px；现有小图标需扩展命中区域，不代表本原型已通过完整WCAG评审。[S24]

所有复杂表单保留离开确认、字段级错误、服务器错误和版本冲突。关闭弹窗返回触发点；键盘焦点不穿透弹层；异步更新适度通告，不反复抢焦点。统一Drawer、ModalDialog、ActionMenu等已有组件，不另造平行组件库。

“保存”只保存当前明确分区；跨分区有未保存修改时提示，不静默丢弃。变更预览指管理操作差异，不是强制发帖预览。成功状态与后台同步失败分开描述，例如“已保存，列表刷新失败”。

审计A22是将既有审计记录集中呈现，不默认新增审计业务。前后台地址先沿用已有路由；页ID只是设计编号，不是API或已建生产URL。

## 4. 逐页实现说明

### A01 工作台

**内容结构**：待办、授权内摘要、快捷入口；不放装饰横幅。

**主要流程**：选举报/用户/版块→直达对象→处置→返回原筛选位置。

**必须覆盖的状态与边界**：部分摘要失败独立重试；未知数显示暂不可用，不当作0。

**原型入口**：页码选择器 `A01`，原型内部片段 `#dashboard`。**截图**：`designs/A01-dashboard-desktop.png`。**任务**：DYR-005 / DYR-007 / DYR-017。

### A02 用户列表

**内容结构**：搜索、状态、用户组和最近活动筛选；姓名优先。

**主要流程**：搜索→用户详情；批量操作进入明确选择模式。

**必须覆盖的状态与边界**：跨页勾选范围明确；禁言不等于删除；无管理权限只能查看获准资料。

**原型入口**：页码选择器 `A02`，原型内部片段 `#users`。**截图**：`designs/A02-users-desktop.png`。**任务**：DYR-008 / DYR-012。

### A03 用户详情

**内容结构**：账号状态、有效用户组、授权来源、内容与治理记录。

**主要流程**：授予附加身份→预览有效期→确认；权限检查带入该用户。

**必须覆盖的状态与边界**：敏感字段独立授权；不同管理员的可见分区不同；撤销保留记录。

**原型入口**：页码选择器 `A03`，原型内部片段 `#user-detail`。**截图**：`designs/A03-user-detail-desktop.png`。**任务**：DYR-008 / DYR-013 / DYR-016。

### A04 用户组

**内容结构**：基础/附加身份列表、加入方式、主要能力、状态。

**主要流程**：按名称筛选→编辑；选2–4组比较；查看组内成员。

**必须覆盖的状态与边界**：访客只是访问场景；不列版主和管理员；无成员统计契约不填假数。

**原型入口**：页码选择器 `A04`，原型内部片段 `#groups`。**截图**：`designs/A04-groups-desktop.png`。**任务**：DYR-008 / DYR-009。

### A05 编辑用户组

**内容结构**：基本资料、社区权限、限额、成员、变更记录；审核分区。

**主要流程**：改能力/额度→查看差异→保存；必要时复制已有组配置。

**必须覆盖的状态与边界**：未勾选为本组不提供；0不等于无限；旧revision不覆盖； MiB转换后再提交。

**原型入口**：页码选择器 `A05`，原型内部片段 `#group-edit`。**截图**：`designs/A05-group-edit-desktop.png`。**任务**：DYR-009。

### A06 用户组对比

**内容结构**：按操作和额度对比；显示仅差异开关。

**主要流程**：选择组→对比授权来源→进入对应组编辑。

**必须覆盖的状态与边界**：对比的是组规则而非具体用户最终权限；不存在的类型不合并。

**原型入口**：页码选择器 `A06`，原型内部片段 `#group-compare`。**截图**：`designs/A06-group-compare-desktop.png`。**任务**：DYR-009 / DYR-013。

### A07 版块目录

**内容结构**：真实父子树、排序、名称、显示状态、访问摘要。

**主要流程**：当前父版块新增子版→编辑；合并/删除前看影响。

**必须覆盖的状态与边界**：不能移入自身子孙；旧内容、访问规则和链接变化必须明确。

**原型入口**：页码选择器 `A07`，原型内部片段 `#boards-admin`。**截图**：`designs/A07-boards-admin-desktop.png`。**任务**：DYR-010。

### A08 版块设置

**内容结构**：基本信息、浏览与发帖、管理人员、外观、高级操作。

**主要流程**：名称选择用户组/权益；图标选择；就地任命带入范围。

**必须覆盖的状态与边界**：隐藏入口不等于允许直链；预设只生成现有引擎支持的规则。

**原型入口**：页码选择器 `A08`，原型内部片段 `#board-settings`。**截图**：`designs/A08-board-settings-desktop.png`。**任务**：DYR-010 / DYR-011 / DYR-012。

### A09 版块有效权限

**内容结构**：版块×用户组场景的有效结果矩阵，允许/不提供/需具体用户。

**主要流程**：选择版块和场景→点击来源→转具体用户检查。

**必须覆盖的状态与边界**：第一版只读结果；不是任意点击格子写一套新引擎；父子策略按现有契约。

**原型入口**：页码选择器 `A09`，原型内部片段 `#permissions`。**截图**：`designs/A09-permissions-desktop.png`。**任务**：DYR-011 / DYR-013。

### A10 管理人员

**内容结构**：管理人员、职务模板、管理范围、状态与来源。

**主要流程**：按版块筛选→任命/查看；移除前显示影响。

**必须覆盖的状态与边界**：管理角色不通过积分购买；范围不默认为全站；最后管理员保护。

**原型入口**：页码选择器 `A10`，原型内部片段 `#team`。**截图**：`designs/A10-team-desktop.png`。**任务**：DYR-012。

### A11 角色与任命

**内容结构**：选用户、模板、范围、支持时才出现有效期和子版选项。

**主要流程**：选择模板→显示实际能力→任命前确认。

**必须覆盖的状态与边界**：只授予操作者有权授予的能力；过期或版本冲突需要重新检查。

**原型入口**：页码选择器 `A11`，原型内部片段 `#role-edit`。**截图**：`designs/A11-role-edit-desktop.png`。**任务**：DYR-012。

### A12 权限检查

**内容结构**：用户/版块或内容/动作/检查时间；结果、来源、额度。

**主要流程**：选择场景→只读检查→有权限时展开来源。

**必须覆盖的状态与边界**：不调用扣额度函数；脱敏失败原因；结果为快照，实际操作重新判权。

**原型入口**：页码选择器 `A12`，原型内部片段 `#inspect`。**截图**：`designs/A12-inspect-desktop.png`。**任务**：DYR-013 / DYR-028。

### A13 成长规则

**内容结构**：经验等级、阈值、奖励来源、启用状态和规则说明。

**主要流程**：编辑少量等级规则→看影响→保存；查奖励来源。

**必须覆盖的状态与边界**：不把积分余额当EXP；不同时启用内置和Wasm两套奖励执行器。

**原型入口**：页码选择器 `A13`，原型内部片段 `#growth`。**截图**：`designs/A13-growth-desktop.png`。**任务**：DYR-014。

### A14 积分账本

**内容结构**：余额、收支、前后余额、原因、操作人、请求编号。

**主要流程**：选用户→调整积分→原因与确认→追加流水。

**必须覆盖的状态与边界**：不编辑历史流水；负数结果拒绝；重复请求不得重复记账；原型仅模拟。

**原型入口**：页码选择器 `A14`，原型内部片段 `#points`。**截图**：`designs/A14-points-desktop.png`。**任务**：DYR-015。

### A15 勋章

**内容结构**：名称、图样、公开展示策略、授予/撤销记录。

**主要流程**：编辑勋章→查看成员→按权限授予或撤销。

**必须覆盖的状态与边界**：图样加载失败有文字兜底；撤销不删除历史；公开展示与后台记录分离。

**原型入口**：页码选择器 `A15`，原型内部片段 `#medals`。**截图**：`designs/A15-medals-desktop.png`。**任务**：DYR-016。

### A16 会员权益

**内容结构**：权益类型与版本、有效期、权限和额度快照。

**主要流程**：选择人和权益→预览作用→确认授予；查看来源。

**必须覆盖的状态与边界**：更新类型不偷偷改历史快照；关闭兑换不撤销已授予权益。

**原型入口**：页码选择器 `A16`，原型内部片段 `#entitlements`。**截图**：`designs/A16-entitlements-desktop.png`。**任务**：DYR-016 / DYR-024。

### A17 主题管理

**内容结构**：主题列表、版块/状态/作者/时间筛选、上下文侧栏。

**主要流程**：选主题→查看正文/修订→处置并记录原因。

**必须覆盖的状态与边界**：每项重新授权；批量部分失败单列；退出详情保留筛选。

**原型入口**：页码选择器 `A17`，原型内部片段 `#moderation`。**截图**：`designs/A17-moderation-desktop.png`。**任务**：DYR-017。

### A18 评论管理

**内容结构**：评论内容、所在主题、楼层、父回复和作者。

**主要流程**：打开上下文→隐藏/恢复等已有操作→结果记录。

**必须覆盖的状态与边界**：目标已删除有占位，不展示越权内容；不把举报状态当内容状态。

**原型入口**：页码选择器 `A18`，原型内部片段 `#comments`。**截图**：`designs/A18-comments-desktop.png`。**任务**：DYR-017。

### A19 举报处理

**内容结构**：举报队列、原因、上下文、历史处理与关联对象。

**主要流程**：工作台直达→核查→处理内容/账号→完成举报。

**必须覆盖的状态与边界**：处理举报与处置内容明确区分；重复处理冲突；失败项可重试。

**原型入口**：页码选择器 `A19`，原型内部片段 `#reports`。**截图**：`designs/A19-reports-desktop.png`。**任务**：DYR-017。

### A20 编辑审核

**内容结构**：待审编辑、原文/新文差异、提交人、时间。

**主要流程**：审阅差异→通过/拒绝→原因→返回。

**必须覆盖的状态与边界**：关闭编辑审核的在途项要有过渡策略；版本过期不覆盖新内容。

**原型入口**：页码选择器 `A20`，原型内部片段 `#reviews`。**截图**：`designs/A20-reviews-desktop.png`。**任务**：DYR-017 / DYR-023。

### A21 风控告警

**内容结构**：风险信号、作用范围、状态、触发依据、规则入口。

**主要流程**：查看信号→核查对象→记录处理结果。

**必须覆盖的状态与边界**：信号不等于定罪；只复用现有处置，不能因UI状态自动封禁。

**原型入口**：页码选择器 `A21`，原型内部片段 `#risk`。**截图**：`designs/A21-risk-desktop.png`。**任务**：DYR-017。

### A22 审计记录

**内容结构**：操作人、对象、时间、动作、请求编号、结果。

**主要流程**：从具体操作跳转→查看上下文→按权限筛选。

**必须覆盖的状态与边界**：只读追加；日志脱敏；无审计权限不下载全部再隐藏。

**原型入口**：页码选择器 `A22`，原型内部片段 `#audit`。**截图**：`designs/A22-audit-desktop.png`。**任务**：DYR-017 / DYR-028。

### A23 扩展管理

**内容结构**：内置扩展与外部Wasm两个区；编译/配置/业务状态。

**主要流程**：启用检查依赖；停用显示新动作/历史/任务影响→确认。

**必须覆盖的状态与边界**：不靠数据库插件enabled模拟运行时；关闭不删数据、不重复任务。

**原型入口**：页码选择器 `A23`，原型内部片段 `#extensions`。**截图**：`designs/A23-extensions-desktop.png`。**任务**：DYR-023 / DYR-024 / DYR-025。

### A24 数据报表

**内容结构**：时间范围、数据口径、更新时间、可用状态。

**主要流程**：筛选范围→查看实际支持报表；导出沿用已有契约。

**必须覆盖的状态与边界**：未启用与加载失败分开；不新增虚构在线人数或浏览量。

**原型入口**：页码选择器 `A24`，原型内部片段 `#analytics`。**截图**：`designs/A24-analytics-desktop.png`。**任务**：DYR-005 / DYR-024。

### A25 站点设置

**内容结构**：品牌、邮件、存储、安全分区；按页加载。

**主要流程**：进入分区→修改→测试/校验→保存；需重启项提示。

**必须覆盖的状态与边界**：密钥只写/脱敏；不改已绑定登录方式；页面失败不拖垮管理后台。

**原型入口**：页码选择器 `A25`，原型内部片段 `#settings`。**截图**：`designs/A25-settings-desktop.png`。**任务**：DYR-026。

### A26 运维与备份

**内容结构**：健康状态、基础日志、可选告警、备份与恢复说明。

## 5. 重点流程的实施级约束

用户组编辑：GET载入revision→本地修改→只读差异→提交expected_revision→409保留本机输入并显示远端版本→用户选择重载/重新编辑。复制用户组须明确复制权限和额度，不复制成员、历史授权或管理角色。成功后刷新组摘要和有效权限相关缓存。

权限矩阵：分清“组模板场景”和“具体用户场景”。组模板无法决定该用户的账号限制、附加权益和当日使用量，不应直接宣称任一用户都能完成操作；用“本组提供，仍需具体用户检查”。授予和拒绝来源分别呈现，禁止用同一个开关暗示所有层级全局优先级。

权限检查：选择具体目标与操作，显示 evaluated_at、规则版本、允许/拒绝/无法判断、可见来源、相关限额与用量；数据源错误不默认允许。客户端诊断结果不是访问令牌。导出/复制诊断记录需独立脱敏，不能带会话密钥。

通知：只读本人的数据，filter+cursor+limit服务端一致处理。单条已读提交成功但计数刷新失败时显示同步中/重试，不用当前页数量覆盖全局。全部已读的截止点或事务快照在契约中明确。

发布器：保存状态不是单个布尔值。本机成功但云端失败显示“已保存到本机，云端未同步”；文件仍在内存且未持久化时不能称完整草稿可恢复。未解决上传默认阻止发布并提供移除/重试。最终关闭必须给主动放弃机会，但不会误报安全保存。

## 6. 原型能做什么、不能做什么

原型支持页码导航、名称搜索、权限开关、变更确认、比较跳转、管理人员确认、模拟权限检查、草稿失败与关闭确认、图片顺序变化、全局未读模拟、会员/设置页签、手机菜单。部分次级按钮和筛选仅展示布局或提示，真实API、数据库、上传、鉴权、持久化、批处理与导出均未接入。

所有修改只在当前页面内存中模拟；刷新重置。原型没有实际账户登录，也不接受真实密码、验证码或密钥。它不能用作管理工具部署到生产，也不能用原型UI判断安全性。HTML可以离线打开，不需要安装依赖或启用开发服务。

原型检查仅覆盖本包记录的页面/宽度和模拟交互，不代表真实浏览器兼容、屏幕阅读器验证或原应用E2E完成。完整实施仍按第五章的验收执行。
