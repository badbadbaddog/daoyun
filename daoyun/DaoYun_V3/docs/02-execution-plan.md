# 执行计划与30张任务卡

全部仓库任务当前PLANNED。本轮仅产出方案和静态原型。每张卡只在前置任务与依赖证据可用后开始，不能把方案编写当实现完成。

## 执行硬规则

先读交接并确认Git根和项目子目录；禁止git reset --hard、git clean、覆盖未提交改动、盲目git add .、删除失败测试或降低CSRF/权限/沙箱来通过门禁。只暂存具体路径。线上数据库、用户数据导出、密钥、生产部署和不可逆迁移需单独明确授权。

保留现有依赖与锁文件。测试数据库必须隔离，不能将生产DATABASE_URL用于测试或自动迁移。逐任务补失败用例，再小步实现，复验定向测试与相关契约，保存截图/HAR/日志，最后更新交接。不能只有单测没有真实页面链路，也不能只有截图没有API断言。

状态：PLANNED → IN_PROGRESS → REVIEW → DONE；受阻记BLOCKED。DONE必须同时有代码/测试/手工链路/证据/交接；“已提交”不等于“已部署”。运行失败、未运行与环境限制分开记录。
