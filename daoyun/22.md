## Rust 编译环境

本机默认 MSVC host 缺少 `link.exe`，但 MSYS2 GNU toolchain 可用，无需安装 Visual Studio Build Tools：

```bash
export PATH="/c/msys64/mingw64/bin:$PATH"
cargo +1.94.1-x86_64-pc-windows-gnu <command>
```

`C:\msys64\mingw64\bin\gcc.exe` 与 `1.94.1-x86_64-pc-windows-gnu` toolchain 均已安装。
`docs/project-status.md` 第 728 节记录过此前已用该组合完成 workspace 测试与 Clippy 验收。
2026-08-21 已用该组合验证 `cargo test --workspace` 与 `cargo clippy --workspace --all-targets -- -D warnings` 通过。
